# Hand-drawn heading font

Source: [LXGW WenKai Lite](https://github.com/lxgw/LxgwWenKai-Lite), Regular.
Upstream font: https://raw.githubusercontent.com/lxgw/LxgwWenKai-Lite/main/fonts/TTF/LXGWWenKaiLite-Regular.ttf

License: SIL Open Font License 1.1; the complete upstream license is included in
`OFL.txt`. Web-only WOFF2 conversion and subsetting retain upstream font names as
permitted by that license. This file is a web asset, not an installable desktop font.

The WOFF2 includes GB2312 Chinese characters, Latin U+0020–U+024F, general and CJK
punctuation, and full-width forms. Characters outside that coverage fall back to
the following fonts in the CSS stack. It is used for headings and the wordmark;
document body text retains the regular sans-serif stack.

The font is served locally, so activating the skin adds no third-party font request.
