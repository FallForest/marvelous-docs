# 编辑器手绘覆盖与新建流程

本轮补齐代码块、顶部、格式工具栏、底部状态栏，以及纸面、表格、任务框和
评论输入区。全部截图来自实际 AppRoot 与 Tiptap，使用独立的内存 REST 数据，
未修改用户数据库。截图环境关闭 Yjs 网络传输，生产协作配置保持原状。

## 实现

- 顶部：真实纸纹、铅笔分隔线、文档图标、手写标题和协作头像纸底。姓名首字
  仍为真实文字，保存、保存中和失败各自按真实状态呈现。
- 工具栏：新增 AI 撤销、重做、加粗、斜体、下划线、链接、表格与代码图标；
  格式与字号控件使用铅笔边框，手机保留更多格式入口。
- 代码块：纸面与铅笔边框、独立语言按钮、移动/删除和复制操作。代码保留
  等宽字体、语法高亮和块内横向滚动，顶栏位置仍从实际 pre 边界测量。
- 底栏：铅笔线、纸纹、字数、随保存状态变化的标记，以及真实键帽。
- 正文：纸面边框随滚动容器保持固定；任务框仍是原生 checkbox，引用使用
  真实涂抹图片；表格保留选区覆盖层与列宽手柄，评论框使用纸笺材质。
- 新建：默认显示空白文档、新建文件夹和 Markdown 导入。会议、周报、项目等
  办公模板放入可选子页，重新打开菜单回到主入口；API 未提供模板时不显示
  本地虚构的模板条目。旧文档和服务器模板接口未改动。

本轮新增 13 份 AI 素材，累计 37 份。原始 PNG 与完整提示词分别位于上一级
`sources/` 和 `asset-prompts-v3.md`；网页素材包为
`marvelous-docs-handdrawn-v3-web.zip`。

## 验证

- 单元测试 254 项通过（Web 124、服务器 76、CLI 54）。
- Web 生产构建通过；ESLint 0 错误，保留 8 条已有警告。
- 原有浏览器回归通过：PDF、块操作、回收站、文本选择、评论锚点与主题。
- 实际 AppRoot 检查通过：代码复制准确、语言菜单可用、工具栏与 pre 对齐、
  任务勾选与保存、素材加载、外观往返保留正文/撤销/评论草稿。
- 默认新建没有 templateId 和预设正文；模板子页可返回、重开复位，空目录
  不展示模板入口。
- 375 px 短屏菜单未越界，侧栏按钮与文档树无重叠；390 px 页面没有横向溢出，
  长代码仅在代码块内滚动。

具体自动检查记录见 `verification.json`；素材检查记录位于上一级
`asset-verification-v3.json`。截图不是生产数据库和实时多人协作的端到端验收。
