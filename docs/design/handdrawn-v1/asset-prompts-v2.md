## search / 放大镜

```text
Use case: illustration-story
Asset type: a production-ready standalone transparent raster UI icon for the Chinese collaborative editor Marvelous Docs.
Input image role: attached editor concept is STYLE REFERENCE ONLY, never reproduce the app screen.
Art direction: match its warm ivory stationery and human graphite-pencil drawing. Noticeable real pencil grain, slightly irregular graphite pressure and warm paper fibers inside solid shapes. Sparse pale sage and butter yellow pigment, charcoal contours. Refined and readable, not childish, flat front view, no perspective or 3D.
Small UI legibility: simple bold silhouette and few internal marks; strong dark graphite line weight, optically about 1.5 pixels when used at 28px. No delicate extra hatching. Object occupies about 82% of a square canvas with transparent safety margin. Entire shape visible and unclipped.
Background: real alpha transparency outside the icon and in holes. No white rectangle, no fake checkerboard, no green screen or background shadow. Warm ivory interior only where the object requires it. No labels, letters, words, watermark, captions, UI screenshot, extra objects or scenery.
Requested asset: ONE simple hand-drawn magnifying glass. Circular lens with truly transparent clear interior, a warm ivory paper-like rim with a small pale sage accent, charcoal graphite rim, short thick handle slanting down to the right. Familiar search silhouette, no contents inside lens.
```

## pencil-frame / 铅笔边框

```text
Use case: illustration-story
Asset type: reusable nine-slice transparent GRAPHITE BORDER MATERIAL for real web UI controls. Attached editor screenshot is material style reference only.
Primary request: draw ONE hollow square frame only, front-facing and axis aligned, a hand-drawn graphite pencil rounded rectangle, on a truly transparent background. All the large inside area must be genuinely transparent, no paper fill at all. This is only the perimeter pencil stroke.
Square canvas ideally 1024 by 1024. Frame runs near x=24, y=24, x=1000, y=1000, leaving just 24 pixels of clear outer margin on all four sides. No wide empty padding. Corner radius about 40 pixels, gently irregular organic corners, almost straight long edges with tiny hand wobble. Consistent dark charcoal graphite stroke around 12 pixels wide at this canvas size, visible broken pencil grain and pressure variation, occasional subtle doubled graphite striation. No large waves, no sketch crosshatching, no arrow, no center art, no words, no numbers, no white or colored surfaces, no cast shadow, no 3D, no label. The perimeter must be closed, all corners complete and uncropped. Keep all 4 corners and edge centers clean for nine-slice CSS border-image scaling. Matte real pencil texture, not a clean vector line.
Output actual alpha transparency both inside and outside the outlined frame. No checkerboard and no green background.
```
