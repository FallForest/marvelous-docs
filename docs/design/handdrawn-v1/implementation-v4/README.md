# 工具栏与状态栏协调

格式工具栏和底部状态栏共用编辑区的一层淡纸纹背景，两栏自身透明，去掉独立
的黄色纸带、上下双横线和阴影。保留低强度铅笔分隔线，正文继续使用独立纸页。

格式命令统一使用同一套 18 px 单色线条图形、1.65 px 笔画。桌面按钮和下拉
控件均为 32 px 高，手机保留 44 px 高的触控区域。手绘质感由真实 AI 纸纹、
浅铅笔边框和鼠尾草绿选中笔触承载，不再混排粗炭笔字母和彩色贴纸。

底栏文字、字数和保存状态统一为 14 px；快捷键提示为 12 px，移除白色键帽
和额外的图标底座。字数与状态仍为真实动态数据。
