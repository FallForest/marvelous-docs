# 直接新建与自动命名

点击“新建”主体直接打开空白文档并进入正文，不先选模板或填写标题。旁边下拉
保留新建文件夹和 Markdown 导入。现有预设移到侧栏独立的“模板库”，本轮未
增加预设，也未实现未来的“保存为我的模板”。

新文档随保存内容自动命名：首个非空 H1 优先，否则取首个非空正文/标题行，
归一空白并截取最多 40 个 Unicode 字符。代码、表格和图片不参与取名；没有
可用文字时暂为“未命名文档”，标题区、侧栏和列表显示创建时间辅助区分。

手动修改标题后，数据库中的命名模式永久变为 manual，正文、实时协作和后续
刷新不会重新启用自动命名。后台自动保存不会覆盖正在输入的标题。其他人已
提交的手动名称会提示确认；切换新文档也不会把旧文档待保存的内容写到新页。

## 数据迁移

`004_document_title_mode.sql` 增加命名模式字段。已有文档一律保留名称并设为
manual，避免猜测旧占位名称是否由用户手动确认。服务端正常启动时自动执行
迁移；没有对用户数据库手动执行 SQL。
