# 菜单与代码块交互修复

收藏徽标改为内部居中、固定行高并禁止压缩。验证了 1、12、99+ 的实际字形，
横向中心误差不超过 0.41px，纵向不超过 0.25px。两主题使用同一布局。

新建菜单的双滚动条来自手绘边框伪元素向外多出的 1px。边框现收在面板内，
正常空间下无滚动条；极矮窗口仅出现必要的纵向滚动。Popover 同时修复自然
高度、视口限宽、缩放坐标和定位后聚焦，随嵌套滚动、锚点尺寸和视口变化重排。

## 代码块

此前标题栏独立 portal 到 body，通过 fixed 坐标追随代码，因而不能被纸张
裁切；下移则使用了删除前的插入坐标。现在标题栏和正文同属 React NodeView，
移动、删除、创建副本和插入正文统一复用块菜单。

- 标题栏保留语言、自动换行、复制及“⋯”。去掉重复常驻的上下箭头和删除按钮。
- 长行在代码区域内横向滚动；换行开关只影响显示，不改存储或复制内容。
- 更改语言不移动正文光标。复制使用当前节点原文，反馈不会撑动邻近按钮。
- 菜单在首尾禁用无效移动；长代码块可以越过短段落，下移后仍保留光标与焦点。
- 左侧拖动柄区分普通点击与超过 4px 的拖拽，两者使用同一套结构命令。
- 嵌套代码跟随其所属顶层列表或引用操作；删除唯一块后保留有效空段落。
- Enter / Shift+Enter 换行，Tab / Shift+Tab 缩进，Ctrl/⌘+Enter 或末尾三次
  Enter 继续正文。非空代码开头的 Backspace 不再清空、降级或合并代码。
- 块操作在普通历史和 Yjs 历史中均独立撤销，不与前后的输入合并。

交互参考 [Notion 代码块说明](https://www.notion.com/help/code-blocks) 中的语言、
复制和换行控制，以及 [Tiptap 代码块文档](https://tiptap.dev/docs/editor/extensions/nodes/code-block)
和本项目已安装的 Tiptap 2 源码。此处把通用块操作合并到现有菜单，未增加代码
执行等功能。完整键盘约定见 ../../../EDITING.md。
