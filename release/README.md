# release/

Committed release artefacts.

`latest.json` is the manifest the update agent and the in-app update check read:
`version`, `releaseUrl`, `notesUrl`, `apiImage`, `webImage`. It is bumped with
the version during a release (see [docs/RELEASING.md](../docs/RELEASING.md)) and
regenerated by `.github/workflows/release.yml`, which publishes the same file as
a release asset.

It lives here rather than in the repository root so the root holds only entry
points: manifests, configuration, and the README.
